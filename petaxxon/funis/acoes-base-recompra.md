# Funil: Ações na Base / Recompra — tipo: Base/Recompra

> **Status:** a testar  ·  **Rota:** A (já são contatos → nutrir → vender de novo)
> **Produto(s):** portfólio (recompra e ascensão de oferta)  ·  **Dono:** [a confirmar]

## 1. O que é & quando usar
Ações recorrentes para **monetizar quem já é contato/cliente** — recompra e ascensão de oferta — via
e-mail/WhatsApp. É o ativo **mais barato de converter** (já conhece a marca). Use de forma contínua para
extrair receita da base sem custo de aquisição novo.

## 2. Estrutura (blocos) — o caminho do lead
```
Segmento (por produto comprado) → Campanha e-mail/WhatsApp → Oferta (recompra/ascensão) → Checkout+esteira
```
