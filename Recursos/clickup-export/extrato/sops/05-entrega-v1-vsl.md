# SOP: Entrega da V1 da VSL Principal

**Fonte:** Task de template no space Gestao
**Responsavel:** Editor de Video → Head de Edicao (revisao)

## Fluxo

1. Dentro do doc da copy deve haver um **link de referencia para edicao**
2. Se nao tiver: cobrar no canal do Discord o **Gestor de Projetos** e **Copy responsavel**
3. Quando estiver em revisao do Head de Edicao:
   - Mudar status para **"REVISAO"**
   - Colocar o **Head de Edicao como responsavel** junto com voce
4. Quando aprovada pelo Head:
   - **Concluir a tarefa**
5. Se houver alteracoes necessarias:
   - Uma **nova tarefa separada** sera criada para o copy documentar as alteracoes
   - O editor NAO precisa iterar na mesma task

## Regra

A V1 e um entregavel unico. Correcoes vao em task separada, nao em ciclo na mesma task.
