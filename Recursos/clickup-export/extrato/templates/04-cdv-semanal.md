# Template: CDV Semanal (Ciclo de Live)

**Frequencia:** Semanal
**Produto:** Clube de Viagens — R$1.997/ano, 10 fichas de cotacao
**Plataforma:** HotWebinar
**Ciclo:** Live terca 20h → Carrinho 48h → Fecha quinta 19h

## 9 Fases

### Fase 01 — Definicoes Estrategicas (6 tarefas)

```
├── Definir promessa da semana
├── Definir oferta
├── Definir narrativa
├── Definir design
├── Definir ciclo
└── Definir termo
```

### Fase 02 — Captacao Pago (7 tarefas)

```
├── Pagina de captura
├── Pagina de obrigado
├── Ads estaticos
├── Ads video
├── TypeBot
├── FormMeta
└── CTWA (Click-to-WhatsApp Ad)
```

### Fase 03 — Captacao Organico + Base (7 tarefas)

```
├── ManyChat Instagram
├── Conteudo IG
├── Emails para base
├── SMS
├── Banners
├── 1a1 grupo WhatsApp
└── 1a1 ebook
```

### Fase 04 — ShowUp (6 tarefas)

```
├── WhatsApp automatico
├── 1a1 mensagens
├── Email
├── Ads remarketing
├── Depoimentos
└── Countdown
```

### Fase 05 — Producao Live (5 tarefas)

```
├── Script da live
├── Slides
├── Guia de naturalidade
├── Configurar HotWebinar
└── Playbook do chat
```

### Fase 06 — Vendas 48h (10 tarefas)

```
├── Pagina de vendas
├── Checkout
├── Email 1 (pos-live)
├── Email 2 (prova social)
├── Email 3 (ultimo dia)
├── WhatsApp msg 1-5
├── Ads remarketing vendas
├── Super-interessados (1a1)
├── Comercial
└── Cross-sell alunos existentes
```

### Fase 07 — Pos-Venda (6 tarefas)

```
├── Email compra confirmada
├── Onboarding
├── Engajamento 7 dias
├── NPS
├── Encerramento
└── Recuperacao (compra cancelada)
```

### Fase 08 — Infraestrutura Tecnica (5 tarefas)

```
├── Configurar SendFlow
├── Configurar GHL
├── UTMs
├── Pixel Meta + eventos conversao
└── Pesquisa segmentacao inscricao
```

### Fase 09 — Percepcao de Escala (2 tarefas)

```
├── Playbook semanal
└── Metricas
```

## Calendario Semanal

| Dia | Acao |
|-----|------|
| Sexta/Sabado | Preparar conteudo da live |
| Domingo | Email D-2 (antecipacao) |
| Segunda | Email D-1 (prova + promessa) + msgs 1:1 |
| Terca | Live 20h (HotWebinar) |
| Quarta | Email vendas + WhatsApp vendas |
| Quinta | Ultimo dia carrinho (fecha 19h) |

## Metricas de Referencia

| Metrica | Meta |
|---------|------|
| CPL (custo por lead) | < R$8 |
| Taxa de Showup | > 35% |
| Taxa de Conversao | > 8% |
| NPS | > 8.5 |
| Taxa de renovacao (12 meses) | > 70% |

**Regra de escala:** 4 indicadores no verde por 3 meses consecutivos.
